RSA Lab

Build a real public-key system with small numbers you can check by hand. Change the primes, watch every value update, then try to break your own key.

1 Pick primes2 Build the keys3 Encrypt4 Decrypt5 Break it

1Pick two primes

Everything in RSA starts with two secret prime numbers, p and q. Their product becomes the public modulus. Use primes between 2 and 1000.

2Build the keys

n = p × q is public. The totient φ(n) = (p − 1)(q − 1) counts the numbers below n that share no factor with n, and only you can compute it. Choose a public exponent e that shares no factor with φ(n). The private exponent d is the number where e × d leaves remainder 1 when divided by φ(n).

Extended Euclid: finding d

3Encrypt a message

Each character becomes its ASCII number m, then c = me mod n. Anyone can do this with the public key.

Show the work for one character
Your turn: what is c for that character?

4Decrypt it

Only the holder of d can reverse the process: m = cd mod n. Paste or edit ciphertext numbers separated by spaces.

5Break your own key

An attacker sees only n and e. If they can factor n, they can rebuild d. Run the attack and see how many divisions it takes. Real keys use n with about 617 digits, which is far beyond any factoring method we know.
